⚠️ Nota: en México, la NOM-030-SSA2-2009 es la referencia normativa aplicable para el expediente clínico institucional; si hay conflicto entre normas para documentación oficial, prevalece la NOM. Tanto NOM-030 como AHA/ACC usan criterios de consultorio; para lecturas domiciliarias el umbral diagnóstico metodológicamente apropiado es ≥135/85 mmHg (ESH 2023), que es el que colorea cada lectura en la tabla de registro. Las tres clasificaciones se muestran en paralelo como referencia comparativa.
